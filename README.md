# 14

Passcode-protected video page (code: 14).

Live: https://nicolasandrafael.github.io/14/

## Add the video
1. Click **Add file > Upload files**.
2. Upload your video named `video.mp4` (or `video.webm` / `video.mov`).
3. Commit. The site updates in a minute or two.

GitHub uploads in the browser are limited to 25 MB per file.
